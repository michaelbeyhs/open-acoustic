# Play Acoustic Remote

`pa-remote.html` is a virtual front panel for a **stock** TC-Helicon Play Acoustic (firmware 1.4.00). It reads and sets parameters live over USB using the firmware's built-in SysEx commands (`22` set, `47` get). No firmware patch is needed.

## Use
1. Connect the pedal by USB. **Quit VoiceSupport** (it corrupts incoming SysEx while connected).
2. Open `pa-remote.html` in **Chrome or Edge** (Mac/PC). Keep `pa-menus.js` and `pa-images.js` next to it.
3. Choose the pedal's ports in the top bar if they aren't picked already, click **Connect** and allow MIDI with SysEx. The status shows "Connected: Play Acoustic".
4. Use the panel like the pedal:
   - soft buttons beside the screen open the menus (preset screen) or select a cell (inside a menu);
   - ◀ ▶ change pages; BACK returns to the preset screen;
   - the knob: drag, scroll or arrow keys, Shift = ×10;
   - HIT toggles HIT.
5. Below the panel: "Live parameter control" (any parameter by name or ID) and the MIDI monitor.

**iPad/iPhone:** Safari and the other iOS browsers have no Web MIDI. Use a MIDI browser app that adds Web MIDI with SysEx, and open the page from a URL (not the Files app).

## What works / what doesn't
See `verify.html` for the current, item-by-item status. In short:
- **Working on the unit:**
  - live set/read of menu parameters;
  - Mix and Setup pages;
  - preset name;
  - the Harmony FX page layout.
- **Not mapped:**
  - preset up/down footswitches;
  - STORE, FAVORITE, GENRE;
  - tuner and looper screens.
- **Writes are allow-listed** (`pa-writes.js`): only the parameters on the pedal's menu pages plus a short expert list can be changed; the rest of the "Any parameter" list is read only. MIDI CTRL (0x278) and FILTER (0x27B), which can lock out USB control (factory reset needed: hold STORE + BACK at power-on, which erases your presets), are never written, nor SYSEXID and the MIDI/CC channels. To write another parameter, add it to `EXPERT` in `pa-writes.js` once it is known to be harmless.

## Touch views (`views/`)
Five touch-screen views of the same pedal, each for a different job: **Pedalboard** (the effect chain as stomp boxes), **Studio editor** (every parameter, EQ/compressor graphs, effect sends, mix, A/B and undo), **Signal grid** (signal flow + inspector), **Stage** (big tiles, HIT, a delay/reverb pad) and **Voice map** (harmony on a pitch ladder, the reverb as a room). Open `views/index.html`.

- One connection, preset bar and set of gestures for all of them (`views/views.js`), on top of `pa-link.js` (the Web MIDI/SysEx link, no UI).
- Values stay in sync both ways: a change in a view goes to the pedal; a knob or switch used on the unit re-reads the values.
- Values only ever come from the pedal; without one the views ask you to connect. Add `?sim` to the address to use a simulated pedal (`views/sim-pedal.js`).
- Preset stepping presses the pedal's front ◀ ▶, so the pedal should be on its preset screen.
- **Read all presets** stores every preset's values on the device, so preset changes need no reading and the preset list can jump straight to any preset (Program Change when the pedal accepts it, front arrows otherwise).
